# ケア議事録 — 医療・介護に特化した議事録作成アプリ

録音データ（会議・カンファレンス・面談・申し送り）を読み取り、医療・介護の様式に沿った議事録を作成するWebアプリです。

## できること

1. **録音データの読み取り**：音声ファイル（mp3 / m4a / wav / webm など）のドラッグ＆ドロップ、またはブラウザでの録音
2. **文字起こし**：Whisper（transformers.js）を**ブラウザ内で**実行。音声データは外部に送信されません。タイムスタンプ付き
3. **医療・介護用語の補正**：「ようかいご→要介護」「じょくそう→褥瘡」などの誤変換を辞書で補正。施設名や薬剤名はユーザー辞書に追加可能
4. **議事録の作成**（Claude API）：7種類の様式から選択
   | 様式 | 主な見出し |
   | --- | --- |
   | サービス担当者会議（第4表） | 検討した項目／検討内容／結論／残された課題 |
   | 退院前カンファレンス | 病状経過／医療処置・服薬／ADL・嚥下／意向／サービス調整／緊急時対応 |
   | 多職種カンファレンス・ケース会議 | 目的／現状／課題／各職種の意見／方針 |
   | 申し送り（SBAR） | 状況／背景／評価／提案 |
   | 診療・訪問記録（SOAP） | S／O／A／P |
   | 家族面談・ACP（人生会議） | 説明内容／本人・家族の意向／合意事項／未決事項 |
   | 施設内委員会・職員会議 | 報告事項／協議事項／決定事項 |

   全様式共通で **⚠ リスク・要注意事項**（転倒・誤嚥・褥瘡・服薬・急変兆候・虐待の疑いなど）、**役割分担・ToDo表**、**次回予定**、**用語補正メモ**を出力します。数値（バイタル・用量）は原文どおりに転記し、不確かな箇所には【要確認】を付けます。
5. **個人情報の保護**：API送信前に、指定した氏名・電話番号・メール・郵便番号・長い番号列をブラウザ内でマスキング
6. **出力**：プレビュー／編集、コピー、Markdown保存、Word形式（.doc）保存、印刷・PDF

APIキーが未設定の場合は、キーワード抽出によるオフライン下書きを作成します。

## 起動方法

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 未設定ならオフライン下書きモード
npm start
# → http://localhost:3000
```

| 環境変数 | 説明 | 既定値 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude APIキー | （なし） |
| `CLAUDE_MODEL` | 使用モデル | `claude-opus-5-5` |
| `CLAUDE_ONLINE` | `ant auth login` のプロファイルで認証するときに `1` を設定 | （なし） |
| `PORT` | ポート番号 | `3000` |

- 文字起こしモデルは初回のみダウンロードされ、ブラウザにキャッシュされます（base 約80MB／small 約250MB）。ダウンロードには cdn.jsdelivr.net と huggingface.co への接続が必要です。WebGPU 対応ブラウザ（Chrome / Edge）では高速に動作します。
- 安全分類器によって生成が拒否された場合は、サーバー側フォールバック（`fallbacks: "default"`）により別のモデルで自動的に再生成されます。

```bash
npm test
```

## 構成

```
server.js                 Express サーバー（Claude API をストリーミング呼び出しし、SSEで返す）
lib/templates.js          議事録の様式とプロンプト
lib/offline.js            APIキーが無いときのオフライン下書き
public/index.html         画面
public/js/app.js          画面のロジック（録音・用語補正・マスキング・出力）
public/js/whisper-worker.js  ブラウザ内の文字起こし（Web Worker）
public/shared/            用語補正辞書・個人情報マスキング（ブラウザとサーバーで共通）
test/                     単体テスト・APIテスト
```

## 注意

生成される議事録は下書きです。記録者が内容を確認・修正したうえで正式な記録としてください。要配慮個人情報を扱うため、Claude API を利用する際は所属機関の個人情報保護規程と「医療情報システムの安全管理に関するガイドライン」等に従ってください。
